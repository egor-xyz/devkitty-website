Privacy

Last updated 2026-11-08.

Summary

Devkitty works on your Mac. It sends two kinds of data by default: anonymous usage analytics and crash reports. Both are on by default, and you can turn each one off in Settings › Privacy. Devkitty has no session replay and does not send your terminal content, your commands or your repository source.

Who we are

Devkitty is a macOS app (bundle identifier app.devkitty.terminal). For questions about this page, open an issue at github.com/egor-xyz/devkitty-releases.

Usage analytics

“Share usage analytics” is on until you switch it off. In Settings it reads: “App launches, build number and which extensions are on. Anonymous.”

Only three events exist: devkitty_first_use, devkitty_launch and extension_state. They carry only these properties:

  • app_build: the build number of your copy of Devkitty;
  • extension_id: which extension, for an extension event;
  • enabled: whether that extension is on;
  • state_reason: whether the event is a snapshot or a change.

Events go to PostHog and to Google Analytics for Firebase. For PostHog, Devkitty creates no person profiles and turns GeoIP off. An anonymous PostHog session identifier is attached while the switch is on. For Firebase, ad storage, ad user data and ad personalization are always denied, and analytics storage is granted only while the switch is on. Devkitty ships with Firebase data collection off at launch.

Crash and error reports

“Share crash reports” is on until you switch it off. In Settings it reads: “Crashes and app errors. Messages and file paths are removed.” Reports go to PostHog’s US cloud (https://us.i.posthog.com).

  • Before sending, Devkitty removes the page URL, referrer, path and IP fields. Any value that contains a home folder path, a file:// address, a web address or a bearer token is replaced with [redacted].
  • Reports use a fixed list of categories, never free text. Devkitty sends at most one report per category every 30 seconds.
  • While reports are on, Devkitty also keeps a local journal of at most 100 entries at ~/Library/Application Support/Devkitty/Diagnostics/events.json, readable only by you.
  • Devkitty does not capture app lifecycle events, screen views or automatic taps, and it has no session replay.

Feature flags

At launch Devkitty asks PostHog for remote feature flags, even when both switches above are off. A flag turns an optional feature on or off. As with any request to a server, PostHog sees the IP address of the connection.

Updates

Devkitty checks for updates once a day by fetching a signed feed from raw.githubusercontent.com/egor-xyz/devkitty-releases. It sends no system profile, and it requires a signed feed and verifies updates. GitHub receives the request, including your IP address and user agent, like any download.

GitHub, GitLab and Bitbucket

Devkitty runs the gh and glab command-line tools you have installed. It does not read or store their tokens. For Bitbucket it reads BITBUCKET_EMAIL and BITBUCKET_API_TOKEN from your environment and talks to api.bitbucket.org directly. Avatars load from github.com without cookies.

AI provider usage

Devkitty reads some account details for Claude and Cursor from files on your Mac. For Cursor it reads Cursor’s local sign-in token and calls only https://cursor.com/api/usage-summary, with redirects refused and no cookies stored. Usage numbers are not part of the analytics events listed above.

Browser sign-in import

If you choose to, Devkitty copies sign-in cookies from Chrome-type browsers, Firefox or Safari into its built-in browser. History and bookmarks are not copied. For Chrome-type browsers, macOS asks you to allow reading that browser’s “Safe Storage” Keychain item. Devkitty uses it to read the cookies, does not keep it, and writes nothing to your Keychain.

Built-in browser

Sites you open see your requests as in any browser. “Translate page” sends the page address to translate.google.com, and only when you use it.

Your terminal

Devkitty does not send your terminal content or commands anywhere. The analytics and crash reports above carry only the fixed fields described there. Devkitty’s session helper opens no network listener.

This website

This website sets no cookies and has no analytics, and its fonts are hosted on the site itself. It stores your Devkitty or Terminal mode choice in your browser’s local storage on your own device. The Download button asks api.github.com for the latest release, and downloads come from GitHub. The site is hosted on GitHub Pages; see GitHub’s privacy statement.

Your choices

Open Settings › Privacy and switch off “Share usage analytics”, “Share crash reports”, or both.

Who receives data

  • PostHog Inc. (US): analytics, crash reports, feature flags.
  • Google (Firebase): usage analytics.
  • GitHub: updates, downloads and this website.
